# Union-Find (Disjoint-Set) Algorithms Analysis & Comparison

این پروژه یک تحلیل جامع و علمی به همراه نمودارهای تحلیلی و گراف‌های بصری پایتون برای ۳ الگوریتم اصلی مجموعه‌های مجزا (Disjoint-Set / Union-Find) بر اساس کتاب الگوریتم‌های سجویک (Robert Sedgewick - Algorithms) ارائه می‌دهد:

1. **Quick-Find (یافتن سریع)**
2. **Quick-Union (اجتماع سریع بدون وزن)**
3. **Weighted Quick-Union (اجتماع سریع وزن‌دار)**

## 🧠 مقایسه تئوری پیچیدگی‌ها (Complexity Analysis)

| الگوریتم | سازنده (Init) | اجتماع (Union) | یافتن / اتصال (Find) | کران ارتفاع درخت | میانگین عمق تجربی |
| :--- | :---: | :---: | :---: | :---: | :---: |
| **Quick-Find** | $O(N)$ | $O(N)$ | $O(1)$ | $\le 1$ (درخت تخت) | $0.82$ |
| **Quick-Union** | $O(N)$ | $O(\text{ارتفاع})$ | $O(\text{ارتفاع})$ | $O(N)$ (امکان تنزل به زنجیر) | $5.12 \sim 279$ |
| **Weighted Quick-Union** | $O(N)$ | $O(\log N)$ | $O(\log N)$ | $\le \lfloor \log_2 N \rfloor$ (تضمین‌شده) | $1.49 \sim 1.81$ |

---

## ⚡ نتایج تجربی نمونه در $N = 5,000$

| الگوریتم | زمان کل (میلی‌ثانیه) | دسترسی به حافظه آرایه | میانگین عمق گره | حداکثر عمق گره |
| :--- | :---: | :---: | :---: | :---: |
| **Quick-Find** | ۲,۴۲۶٫۱ ms | ۲۲,۰۰۰,۰۰۰ | ۰٫۸۴ | ۱ |
| **Quick-Union** | ۳۵۳٫۱ ms | ۳,۴۰۰,۰۰۰ | ۲۷۹٫۶۵ | ۵۲۱ |
| **Weighted Quick-Union** | **۹٫۰ ms** | **۶۸,۰۰۰** | **۱٫۸۱** | **۶** |

> **نتیجه**: الگوریتم Weighted Quick-Union بیش از **۲۷۰ برابر سریع‌تر** از Quick-Find و **۴۰ برابر سریع‌تر** از Quick-Union اجرا شده و ارتفاع درخت را همیشه زیر $\log_2(5000) \approx 12.28$ نگه می‌دارد.

## 🚀 نحوه اجرا (How to Run)

### اجرای تمام تحلیل‌ها با یک دستور:
```bash
python3 run_all.py
```

### اجرای مستقل هر بخش:
- **تولید نمودار ساختار درخت‌ها (مشابه اسلاید):**
  ```bash
  python3 visualize_trees.py
  ```
- **تولید ساختار درختی ۳ الگوریتم:**
  ```bash
  python3 visualize_3way_trees.py
  ```
- **اجرای بنچ‌مارک و نمودارهای مقایسه‌ای ۴ تایی:**
  ```bash
  python3 benchmark.py
  ```
